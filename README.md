# Python Programming Exercises

This repository contains beginner-friendly Python solutions covering arithmetic, conditionals, bitwise operations, loops, number theory, recursion, and patterns.

## Run

```bash
python python_exercises.py
```

Enter an exercise number from 1 to 15, then provide the input requested by that exercise. The individual implementations are kept as functions so the file is executable as a single learning tool rather than a collection of conflicting top-level `input()` calls.

## Included exercises

1. Arithmetic operations
2. Area of a circle
3. Simple interest
4. Celsius/Fahrenheit conversion
5. Divisibility by 3 and 5
6. Greater of two numbers
7. Positive, negative, or zero
8. Check three numbers equal
9. Voting eligibility
10. Character classification
11. Even/odd using bitwise AND
12. Swap using XOR
13. Left and right shift
14. Check kth bit
15. Count set bits
